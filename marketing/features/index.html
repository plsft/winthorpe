Features

Every panel earns its space.

Winthorpe is opinionated about what belongs in an agent IDE. Here's what's in the box and why.

Workspaces

Each workspace is a real git worktree on a fresh branch. No stash-juggling, no "let me commit my WIP first." Spin up three for a feature, archive when you're done. Status (Done / In review / In progress / Backlog) groups them in the sidebar.

Multi-agent sessions

Claude Code (Anthropic) and Codex (OpenAI) are first-class. Run them side by side in the same workspace, or run different agents in different workspaces. One unified chat surface; one unified tool-call stream.

Multi-tab Monaco editor

A real editor, not a viewer. The same Monaco that powers VS Code: full syntax highlighting for every language, multi-cursor, find/replace, bracket matching, IntelliSense for JSON. Click a file, get a tab. Drag to reorder. Ctrl+S to save. Ctrl+W to close. Tab state persists per workspace. Right-click the tree for new file/folder/rename/delete. Defaults to Tokyo Night dark theme.

Real ConPTY terminals

Backed by Windows ConPTY through portable-pty — vim, htop, ssh, tmux, claude, codex all just work. Hover-zoom expands the active terminal so you can read long output without losing context.

Git inspector

Live changes panel, branch state at a glance, push / publish with one click. Bundled gh and glab mean PR creation never leaves the app.

DPAPI-protected credentials

API keys for Anthropic, OpenAI, and the GitHub OAuth Device Flow are stored in a per-user SQLite database, encrypted via Windows DPAPI. No plain-text dotfiles, no Keychain-on-the-wrong-OS hacks.

Win32 Job Objects

Every spawned process — sidecar, agent CLI, terminal child — is attached to a kill-on-close Job Object. Close Winthorpe and every descendant goes with it. No orphaned claude.exe hoarding a GPU thread an hour later.

Filesystem watcher

Backed by notify/ReadDirectoryChangesW — when an agent edits a file, the tree, the change list, and the editor all update without a refresh. 250 ms debounce keeps fan-out cheap.

Custom title bar + Mica

Native chrome ditched in favor of a brand-aware title bar with Mica backdrop on Windows 11. Drag-region carved correctly so WebView2 doesn't intercept clicks. Looks like the platform, behaves like the platform.

Winthorpe CLI

A winthorpe binary on your PATH. Create workspaces, send prompts, inspect state, script repeatable flows — same SQLite database the GUI reads.

Skills (Anthropic Agent Skills)

Drop a SKILL.md + scripts into .claude/skills/ and the LLM picks them up. Repeatable flows — releases, code reviews, migrations — that ride along with the repo.

Local-first by default

SQLite for sessions, transcripts, settings, credentials. No remote DB, no SSO required, no telemetry. Bring your own Anthropic and OpenAI keys; the only network calls are to those providers.

What it isn't

Winthorpe is deliberately not a few things. Knowing what it isn't is half the value of knowing what it is.

Not just a chat client.

Winthorpe runs the agent and lets you edit the resulting code in a real Monaco editor — the chat surface and the editor live in the same window, and you can have several sessions side by side.

Not an AI-completion IDE.

If you want inline ghost-text completion while you type, keep Cursor or VS Code open. Winthorpe's editor is for direct edits during agent review — not autocomplete.

Not a SaaS.

No accounts, no billing, no remote runtime. Your code never leaves your machine unless your agent CLI sends it.
