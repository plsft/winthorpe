Privacy

Last updated: 2026-04-30

The short version

Winthorpe runs entirely on your machine. We — Plural Software — collect nothing. The desktop app makes no telemetry, analytics, or "phone-home" requests. The only outbound network traffic is the one you trigger by talking to your agent (Anthropic's API, OpenAI's API, GitHub's API).

What's stored, where

Winthorpe creates a per-user data directory at %LOCALAPPDATA%\Winthorpe\ containing:

  • A SQLite database with your workspaces, sessions, and chat transcripts.
  • A per-user credentials store (also SQLite) for API keys and OAuth tokens. These are encrypted via the Windows DPAPI — only your Windows user can decrypt them.
  • Log files (rotating, 7-day retention) under logs\.

Nothing in this directory ever leaves your machine through Winthorpe.

Network requests Winthorpe makes

  • Anthropic / OpenAI when you talk to Claude Code or Codex — those CLIs are bundled but the API calls go directly to the providers under your account.
  • GitHub for OAuth Device Flow, repo listing, and PR creation via the bundled gh CLI.
  • GitLab if you authenticate the bundled glab CLI.
  • github.com/plsft/winthorpe/releases when checking for updates (you can disable this in Settings).

This website

This marketing site is hosted on Cloudflare Pages and uses no analytics, no cookies, no third-party scripts. Cloudflare retains standard edge access logs (IP, user agent, request path) per their privacy policy; we don't ingest those logs.
