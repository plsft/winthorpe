Built-in editor

Multi-tab Monaco — same engine that powers VS Code.

Capabilities

  • Full syntax highlighting for every language Monaco supports (every language VS Code highlights, it does too).
  • Multi-cursor, find/replace (Ctrl+F), bracket matching, IntelliSense for JSON/CSS/HTML/TS.
  • Multi-tab. Drag tabs to reorder. Ctrl+W closes the active tab.
  • Tab state persists per workspace — close the workspace, reopen it, the same files are open.
  • The pinned Chat tab is always leftmost so you can flip between editor and conversation in one click.
  • Click any file in the file tree to open it. Single click — not double.

Saving

Ctrl+S writes the active tab's contents to disk and shows a Saved <filename> toast. Works from any focus — the chat composer, the inspector, the title bar — because the keybind is at the App level. The File → Save menu entry dispatches the same Ctrl+S event.

Theme

Defaults to Tokyo Night dark (Folke Lemaitre's port). Switch via Settings → Theme (system / light / dark). Monaco's theme follows the app theme automatically — no separate editor-theme picker.

File tree

Left side of the editor view. Right-click any file or folder for: New File, New Folder, Rename, Delete. F2 renames, Del deletes from the keyboard. The tree updates live via the FS watcher — agent edits appear without a refresh.

Performance

Monaco loads lazily on first file open (~150 ms). Language workers (TS, JSON, CSS, HTML) are pre-warmed at idle so the first .ts open doesn't stall. xterm panels stagger their mount across animation frames so a workspace with multiple terminals doesn't block the main thread.

What it isn't

Not an AI-completion IDE. The editor doesn't do inline ghost-text completion the way Cursor does. Edit the agent's output directly during review — that's the design intent.
