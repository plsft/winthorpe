Terminal & PTY

Real ConPTY, real Job Objects, no WSL.

Inspector → Terminal tab

Click the Terminal tab in the Inspector to get an xterm-style terminal panel. Type any command — it runs in a real PTY, not a fake interactive shell. vim, htop, ssh, tmux, the bundled claude or codex CLIs — all work because the terminal speaks ConPTY.

Hover-zoom

Hover the terminal panel and it expands to roughly twice its docked size, anchored to the bottom-right of the inspector. Useful for reading long output (test runs, build errors) without losing the rest of the layout. The zoomed panel is clamped to never overlap the title bar.

Process supervision

Every spawned process — sidecar, agent CLI, terminal child shell — is attached to a Win32 Job Object with JOB_OBJECT_LIMIT_KILL_ON_JOB_CLOSE. Close Winthorpe and every descendant goes with it. No orphaned claude.exe hoarding a CPU thread an hour later.

Scrollback

5,000 lines per terminal. Mod+K (or Ctrl+K) clears the screen and scrollback together. Multiple terminal panels mount with a per-frame stagger queue so a workspace with several terminals doesn't block the main thread.

Onboarding terminals

The same PTY layer powers the embedded terminals during onboarding (gh auth login, claude /login, codex login). Real input, real output, real auth.
