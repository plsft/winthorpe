Menu mnemonics

The top menu bar follows the Windows native convention — each menu has an underlined letter that you can reach with Alt:

  • Alt+F — File
  • Alt+E — Edit
  • Alt+V — View
  • Alt+H — Help
  • Esc closes any open menu
