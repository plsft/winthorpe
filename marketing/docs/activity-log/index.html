Activity Log

Live tail of every internal action.

What it shows

Every tracing event the Rust backend emits — which is everything important Winthorpe does internally. That includes:

  • Every git invocation (target, args, exit, duration)
  • Sidecar spawn / kill / IPC
  • Agent CLI lifecycle (Claude Code, Codex)
  • FS watcher events (file change, debounce, fan-out)
  • SQLite write / read activity at debug level
  • Every Tauri command dispatch
  • Cost-ledger writes when transcripts get processed
  • Forge (GitHub / GitLab) API calls

How to open it

Click the log icon (three lines with a leading caret) next to the Settings gear in the workspaces sidebar footer. Or View → Activity Log from the menu bar.

Filtering

Level filter: TRACE / DEBUG / INFO / WARN / ERROR. Picking a level shows that level and above. Text filter on the right searches across the target (module path), message, and structured fields.

Live tail

Polls every 750 ms while the modal is open. Auto-scrolls to bottom unless you've manually scrolled up — then it freezes the scroll position so you can read history while events keep arriving. Pause button stops the tail entirely.

Retention

The dialog reads from a 5,000-event in-memory ring buffer (oldest events evicted FIFO). Full history is also written to %LOCALAPPDATA%\Winthorpe\logs\rust.jsonl (10 MB primary + 10 MB rotation backup, JSONL format) — point any log-viewer at that file for unbounded history.

When to use it

Anything weird is happening: a button does nothing, an action takes too long, an editor won't open, a clone fails opaquely. The Activity Log shows the actual command that ran, the actual error, the actual stack of operations. Every ⚠ in the UI corresponds to a WARN line; every error toast corresponds to an ERROR line.
