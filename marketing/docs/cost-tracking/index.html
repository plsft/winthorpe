Cost & tokens

Per-turn ledger, plan tracking, accurate to invoice when on API.

How it works

Winthorpe runs a background scanner every 60 seconds that reads the JSONL session transcripts written by Claude Code (under ~/.claude/projects/) and Codex (~/.codex/sessions/YYYY/MM/DD/). For each session that hasn't been written to in 5+ minutes (the staleness heuristic for "session ended"), it sums the token usage and inserts one row into ai_sessions.

The parser is a direct port of worktale's verified hooks. Schema mirrors worktale's ai_sessions table exactly so a future export-to-worktale sync is a column-for-column copy.

What gets tracked per turn

  • Tokens: input, output, cache-read, cache-write (Claude only)
  • Cost in USD (per-token API rates)
  • Provider + model exact id (e.g. claude-sonnet-4-5-20250929)
  • Tools used (Bash, Edit, Read, Grep, Glob, mcp__github__*, …)
  • MCP servers consulted
  • Duration seconds
  • Workspace + session attribution when known
  • PR-create marker for PR-creation turns specifically

"API-equivalent" — what that means

The cost number is what each turn would cost on the metered Anthropic / OpenAI APIs. If you're on a Claude Pro / Max or ChatGPT Plus subscription, this is your value extracted — what you're getting for the flat plan. If you're on per-token API keys, this is your actual invoice.

The Cost dashboard labels this prominently: the column header is API cost and the footer says "Costs are API-equivalent — what each turn would cost on the metered Anthropic / OpenAI APIs."

Plan usage panel

For Claude Max and Pro, the Cost dashboard's Summary tab shows a Plan usage panel with three live bars from Anthropic's oauth/usage endpoint:

  • 5-hour window — main Max/Pro limit, with reset countdown
  • 7-day window — secondary limit, with reset countdown
  • Opus 7-day sub-limit — separate quota for Opus

Bars are emerald under 70%, amber under 90%, rose above. Pulled from the same OAuth-token Claude Code uses to talk to Anthropic — no separate API key needed.

Per-PR cost chip

When a workspace has produced a PR-create turn, the Inspector header shows a small "Last PR $0.05" chip. The cost includes any retries within the same PR-create session.

History

The dashboard's History tab shows day-by-day cost bars for the last 30 days with activity. Sortable, comparable, no external chart lib — pure CSS.

Reset

The trash-can button in the Cost dashboard header clears every ai_sessions row and the transcript-processed state file. The actual transcripts on disk are not touched — so the next 60-second scan tick reconsiders everything still under ~/.claude/projects/ and ~/.codex/sessions/. To start a true clean slate, also delete or move those source directories first.

Pricing tables

Direct port of worktale's snapshot, kept in src-tauri/src/models/pricing.rs:

  • Claude Opus 4.x: $15 input / $75 output / $1.50 cache-read / $18.75 cache-write per Mtok
  • Claude Sonnet 4.x: $3 / $15 / $0.30 / $3.75
  • Claude Haiku 4.5: $1 / $5 / $0.10 / $1.25
  • OpenAI gpt-5 family: $15 / $60 / $7.50 (gpt-5); cheaper for mini/nano
  • OpenAI o1 / o3 / o4 family + gpt-4.1 + gpt-4o full table

Snapshot 2025-Q4. When Anthropic / OpenAI changes prices, update worktale's table first — these mirror it.
