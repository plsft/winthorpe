Git & PRs

Inspector commit/push/PR + auth recovery on Windows.

Inspector → Changes

Live file-by-file diff view for the active workspace. Insertion / deletion counts. Click any file to see its diff in a Monaco diff editor. Backed by a real-time FS watcher (notify / ReadDirectoryChangesW) so agent edits appear without a refresh. 250 ms debounce.

Inspector → Actions

One-click Commit, Push, Create PR from the workspace's branch. The agent drafts the commit message and PR title/body from the diff; you eyeball, then confirm. PR creation routes through the bundled gh pr create for GitHub or glab mr create for GitLab.

Cloning from your GitHub

The clone dialog defaults to a From your GitHub tab that lists every repo you have access to via gh repo list. Search, click, choose clone location, done. The folder is auto-created if it doesn't exist (and the path is normalized to native separators on Windows). For non-GitHub URLs (GitLab, BitBucket, self-hosted), the From URL tab takes a raw git URL.

GitHub credential auto-recovery

On Windows, raw git push over HTTPS to GitHub fails when Git Credential Manager has no cached credentials and Winthorpe (correctly) sets GIT_TERMINAL_PROMPT=0 to prevent hangs. When this happens, Winthorpe automatically runs gh auth setup-git (which configures gh as the credential helper using your already-authenticated OAuth token), then retries the push once. From then on, every push / fetch / clone over HTTPS to github.com just works.

If the retry still fails, the toast tells you whether to run gh auth status or check your SSH key.

Network-touching commands have hard timeouts

Every git command that may contact a remote (fetch, pull, push, clone, ls-remote) has a wall-clock timeout. Without it, a hung remote or unexpected credential prompt would park a thread forever. The whole git process group is killed (Unix: process_group + SIGKILL; Windows: taskkill /T /F) on timeout.

SSH commands inherit BatchMode=yes, ConnectTimeout=10, and StrictHostKeyChecking=yes so a dead host or missing key fails fast.

No console-window flashes

Every git, gh, glab, claude, codex, npx, and taskkill spawn on Windows is launched with the CREATE_NO_WINDOW flag. No black boxes flashing on screen during agent runs.

Read-side performance

Read-only git invocations (status, log, for-each-ref, rev-parse) pass --no-optional-locks to skip lock contention with whatever else is reading the repo (the FS watcher, your terminal, the activity log polling).
