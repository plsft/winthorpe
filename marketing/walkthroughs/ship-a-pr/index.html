Ship a pull request

5 steps · edit → commit → push → PR

1

Open the file the agent edited

The Inspector → Changes panel shows live diffs. Click any file to open it in the Monaco tab next to your chat.

export function toSlug(input: string): string {
const tokens = tokenize(input);
return tokens.join("-")
.toLowerCase()
.replace(/-+/g, "-");
}
2

Tighten one line, hit Ctrl+S

Real Monaco — multi-cursor, find/replace, all of it. Save with Ctrl+S; toast confirms.

✓ Saved transforms.ts
3

Commit + Push

Inspector → Actions → Commit. The agent drafts a message from the diff. Tweak if you want, confirm. Then click Push.

Commit message
feat(transforms): add slug case

Lowercases input, replaces non-alphanumerics with hyphens, and
collapses repeated hyphens. Tests cover unicode and whitespace.

Auto-recovery on Windows. The first push to a fresh GitHub remote often fails because Git Credential Manager has no cached creds. Winthorpe detects this specific failure pattern, runs gh auth setup-git to wire gh as the credential helper, and retries — invisibly. Push just works.

4

Click Create PR

PR title and body are agent-drafted from the branch's diff against the base. Confirm. gh pr create runs under the hood.

✦ Opened github.com/plsft/typey/pull/47
5

Watch the per-PR cost

A small "Last PR $0.05" chip appears on the Inspector header. The cost is the sum of API-equivalent dollars for the PR-create turn (and any retries within the same session).

$ Last PR $0.05
