Run two agents in parallel

4 steps · the headline differentiator

1

Have one workspace going

Workspace aldebaran is running Claude Sonnet 4.5 on a feature branch. Reasoning is streaming. Don't wait for it to finish.

In progress
aldebaran
claude-sonnet-4-5 · feat/aldebaran
2

Click + New Workspace again

A second workspace, vega, spins up in <1 s. New worktree on disk, new branch, fully isolated from aldebaran's branch.

3

Pick Codex this time

Open vega's model picker, switch from default to gpt-5. Send a different task — say, "Add bash completions for typey." The two agents now run side by side.

In progress
▶ aldebaran Streaming
claude-sonnet-4-5 · feat/aldebaran
▶ vega Streaming
gpt-5 · feat/vega
4

Switch between them with the sidebar

Click aldebaran to read its progress. Click vega to check on Codex. Both keep streaming in the background. Neither knows about the other. When either finishes, the workspace status updates.

Why this works. Each workspace's session, agent process, and worktree are fully independent. Win32 Job Objects keep the agent CLIs scoped — close the app, both die cleanly. No crossover, no shared state.
