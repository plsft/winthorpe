Clone a repo & spin up your first workspace

5 steps · ~90 seconds

1

Click + Add Repository → Clone

From the empty workspace sidebar (or any time later via File → Add Repository…).

Workspaces
2

Pick a repo from your GitHub

The dialog opens to From your GitHub by default with every repo you have access to. Type to filter, click to select.

Clone location

Folder is created if it doesn't exist.

Auth handled. The clone routes through the bundled gh repo clone using the OAuth token from onboarding — no separate Git Credential Manager setup needed for github.com.

3

A Conductor appears

The repo becomes a Conductor in the sidebar. Workspaces hang under it.

4

Click + New Workspace

A workspace named aldebaran (random celestial name) appears under the conductor. Behind the scenes: git worktree add + new branch + a fresh agent session, all in <1 s.

5

Pick an agent & send your first prompt

The composer at the bottom of the workspace lets you pick a model (Claude Sonnet 4.5, Codex gpt-5, …). Type the task; reasoning, tool calls, and file edits stream in.

⌘
claude-sonnet-4-5 ⏎ Send

Your model choice persists. Closing the workspace and reopening it preserves the picked model — written to the session row in SQLite, not in-memory.
