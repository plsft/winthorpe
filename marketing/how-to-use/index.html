Guide

From install to your first agent-driven PR.

Twelve steps, ~10 minutes if you've already got an Anthropic or OpenAI key handy.

1

Install

Grab Winthorpe_0.6.3_x64-setup.exe from the download page and double-click it. The NSIS installer is per-user — no admin prompt — and lands in %LOCALAPPDATA%\Programs\Winthorpe.

If SmartScreen blocks it, click More info → Run anyway. The installer doesn't ship signed yet.

2

First launch

Open Winthorpe from the Start menu. The onboarding flow walks you through: connect GitHub → sign in to your agent of choice → install the CLI → install Skills → import your first repo. You can skip any step and revisit it later from Settings.

3

Connect GitHub

Winthorpe uses GitHub's Device Flow. Click Connect GitHub, copy the eight-character code, hit the in-app button to open github.com/login/device, paste, approve. The first time you'll also be asked to authorize the GitHub CLI — same flow, runs inside an embedded terminal.

Tokens are stored in a per-user SQLite DB encrypted via Windows DPAPI. Nothing on disk in plain text.

4

Sign in to Claude or Codex

You need at least one. Both are bundled — no separate install.

  • Claude Code. Click Sign in to Claude Code → authorize in browser → done. Uses your Anthropic account.
  • Codex. Click Sign in to Codex → authorize via OpenAI → done.

You can swap or add the other later.

5

Install the Winthorpe CLI

Click Set up Winthorpe CLI. It drops a winthorpe.exe + winthorpe.cmd into %LOCALAPPDATA%\Programs\Winthorpe\bin\ and prepends that to your user PATH (no admin needed). Open a fresh PowerShell and try winthorpe --help.

6

Import a repo

Two paths:

  • Local clone you already have. Click Import existing repo, point at the folder.
  • Fresh GitHub repo. Click Clone from GitHub, pick from your list, choose where to clone.

The repo becomes a "Conductor" in Winthorpe parlance — every workspace is a worktree off it.

7

Spin up a workspace

Click + New Workspace. Give it a name (Winthorpe suggests one). Pick a base branch (defaults to main). Pick an agent. Hit Create.

Behind the scenes: git worktree add + new branch + a fresh agent session, all in <1 s.

8

Send your first prompt

Type your task into the chat at the bottom. Examples:

  • "Add a unit test for the rate-limit refresh path"
  • "Replace tabs with spaces in src/lib/"
  • "Migrate UserPrefs to the new SQLite schema"

Reasoning, tool calls, file edits all stream into the chat surface. The git inspector on the right updates live as files change.

9

Review — and edit — the diff

Three ways:

  • Inspector → Changes. File-by-file with insertion/deletion counts, click any file to see the diff in Monaco.
  • File tree → click any file. Opens a full Monaco editor tab. Tweak the agent's code yourself — change a variable name, fix an off-by-one, add a comment. Ctrl+S to save. Tab persists per workspace; right-click the file tree for new file / folder / rename / delete.
  • Inspector → Terminal. Hover-zoom expands a real PTY for git diff, cargo test, anything you'd run by hand.

Monaco defaults to the Tokyo Night theme; Settings → Theme has light / dark / system pickers if you prefer.

10

Commit + push

Inspector → Actions → Commit. Winthorpe drafts a message from the diff; tweak it, hit commit. Then Push publishes the branch.

Pre-commit hooks run as configured. Husky, lint-staged, cargo fmt — none of it has to know it's not a terminal.

11

Open a PR

Click Create PR in the workspace header. Winthorpe asks the agent for a title and body, you eyeball, then it runs gh pr create against your authenticated GitHub. The PR URL pops as a toast — click to open in your browser, or stay in Winthorpe and start the next workspace.

12

Archive when you're done

When the PR's merged, click Archive on the workspace. Winthorpe stops the FS watcher, kills any open terminals tagged with the workspace, removes the worktree, deletes the local branch, and moves the workspace to the Done group in the sidebar — all in one click.

The chat transcript is preserved in the local DB so you can reopen it later as reference.
